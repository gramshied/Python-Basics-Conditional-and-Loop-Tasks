# Python-Basics-Conditional-and-Loop-Tasks
This repository includes two beginner-level Python programs that demonstrate the use of conditional statements (`if-else`) and loops (`for`) for basic tasks.

---

## Task 1: Even or Odd Checker

This program prompts the user to enter an integer and then determines whether the number is **even** or **odd** using an `if-else` statement.

### How it works:
- Uses the modulus operator `%` to check if the number is divisible by 2.
- If the remainder is 0, it prints "The number is even."
- Otherwise, it prints "The number is odd."

---

## Task 2: Sum of Integers from 1 to 50 Using a Loop

This program calculates the sum of all integers from 1 to 50 using a `for` loop.
### How it works:
- Initializes a variable `total` to 0.
- Loops through numbers 1 to 50 using `range(1, 51)`.
- Adds each number to the total.
- Prints the final result after the loop.

---

## Purpose

These programs serve as simple examples to understand:
- Conditional logic using `if-else`.
- Iterative processing using loops.
- Basic user interaction with `input()` and `print()`.
